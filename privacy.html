Privacy Policy

Last updated: November 23, 2026

GTA 6 Moments is a private tool used only by its owner to upload clips to the owner's own YouTube channel and Instagram account. It is not offered to the public.

What we access

With the owner's permission, the tool uses the YouTube Data API to upload videos and read view counts for the owner's channel, and the Instagram API to publish Reels to the owner's account. It does not access anyone else's data.

What we store

Sign-in tokens are stored as encrypted secrets so the tool can upload on the owner's behalf. No personal data is sold, shared, or used for advertising.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be removed at any time at myaccount.google.com/permissions.
